# 全国农业大数据驾驶舱 · 需求记录

状态：已确认。工程：`examples/agriculture`（boardify-agriculture）。

| 需求编号 | 项目 | 确认内容 |
| --- | --- | --- |
| R-01 | 交付形态 | 数据大屏（16:9 定屏等比缩放，设计稿 1920×1080，深色科技风） |
| R-02 | 使用对象 | 面向农业宏观监测/指挥中心；核心问题：全国农业整体态势、省份差异与下钻明细 |
| R-03 | 数据来源 | 固定种子演示数据（显著标注“演示数据”），字段与真实统计口径同构，可整层切换真实接口 |
| R-04 | 指标维度 | 粮食产量（万吨）、农林牧渔总产值（亿元）、土地资源（耕地/播种/灌溉，万亩）、生产要素（农机总动力/化肥/从业/受灾）四大维度 |
| R-05 | 图表与交互 | 年度趋势折线、产业构成环形、区域排行条形、作物构成条形、省级生产要素相对指数雷达；地图指标切换、全国→省→市→区县逐级下钻、面包屑返回、区域选择（键盘可达）、滚轮缩放/拖动平移、全屏切换 |
| R-06 | 视觉 | 深墨青 #081b20、暖白 #f3efe3、丰收金 #dbb96c；顶部 48px 大数字、55% 宽主地图、两翼分析、底部趋势和区域详情；克制分隔线、无荧光描边；单屏无滚动无裁切，等比缩放而非重排 |
| R-07 | 地图 | 全国→省→市→区县四级下钻（区县为最细层级）；真实中国地图 DataV.GeoAtlas 2021.5 本地资源化（3238 节点 / 363 资产）；含台湾与南海诸岛（九段线）；仅供学习交流，未获公开发布许可 |
| R-08 | 网络 | 全部图表与地图本地资源，运行时不依赖外网（构建/测试阻断外网验证） |

## 决策记录

- 2026-10-24：实现已批准重设计，替代旧版绿色科技风与 640px 中列方案。顶部及左翼保持全国口径，地图、排行、详情随下钻联动。
- 2026-10-24：雷达各维度使用省级单位面积指标相对省际最大值归一化（最大值=100），不是官方现代化评分；化肥强度不表示越高越好。市县数据明确为父级确定性分摊。
- 2026-10-24：23 项单元测试通过，类型检查及生产构建通过；1366×768、1920×1080、2560×1440 各 7 项浏览器状态检查通过，包含全国、省、市、区县、返回、指标切换和刷新，阻断外网时无控制台或网络错误。截图及结果位于 `/tmp/boardify-agri-qa/fixed`。构建保留分块超过 500 kB 的体积提示。
