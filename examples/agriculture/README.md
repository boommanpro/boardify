# 全国农业大数据驾驶舱（boardify-agriculture）

基于 boardify 技能构建的 **16:9 数据大屏**：全国农业宏观监测，深色科技风，全国→省级地图下钻。

## 功能

- **四大指标维度**：粮食产量（万吨）、农林牧渔总产值（亿元）、土地资源（耕地/播种/灌溉，万亩）、生产要素（农机总动力/化肥/从业/受灾）。
- **中央地图**：真实中国地图（DataV.GeoAtlas 2021.5，本地资源，含台湾与南海诸岛九段线），按指标填色，**全国→省→市→区县逐级下钻**，面包屑/返回上级/区域选择（键盘可达），滚轮缩放/拖动平移；地图列近方形布局，地图自适应填满面板。
- **指标切换**：地图、区域排行、详情面板随「粮食产量 / 总产值 / 耕地面积 / 农机总动力」联动。
- **区域详情**：省级显示 4 项核心指标 + 农业现代化水平雷达（机械化/灌溉保障/复种指数/土地产出/减施增效）；市/区县显示当前区域四项指标。
- **大屏特性**：1920×1080 定屏等比缩放、实时时钟、全屏切换、演示数据显著标注。

## 使用

需要 Node.js 22 或更新版本。首次先获取地图资产，再安装与运行：

```sh
# 1. 本地化下载真实中国地图（全国 + 省级，仅本地学习，不授权分发）
node scripts/fetch-maps.mjs --learning-only

# 2. 安装与开发
npm ci
npm run dev

# 3. 测试与构建
npm test
npm run build

# 4. 生产预览（浏览器回归前保持运行）
npm run preview -- --port 4173

# 5. 真实浏览器回归（2560 / 1920 / 1366 三视口，阻断外网）
npm run test:browser
```

构建产物位于 `dist`，需使用静态服务器访问，不支持直接双击 HTML；`base: './'` 支持子路径部署。

## 结构

- `src/data/agriculture.ts`：唯一数据出口；固定种子演示数据（省级锚点 + 沿父级链确定性分摊到市/区县），字段与真实统计同构。
- `src/data/maps/manifest.json`：地图清单（全国→省→市→区县 3238 节点、363 资产白名单、许可与处理记录）。
- `src/components/agri-map.tsx`：地图下钻（加载/竞态隔离/错误重试/叶级提示/面包屑/汇总回报）。
- `src/components/agri-panel.tsx`：图表面板 + 可访问数据替代（sr-only 表）。
- `src/lib/charts.ts` / `chart-options.ts`：按需注册 ECharts 模块、统一暗色色板（hex，规避 oklch 兼容坑）。
- `src/lib/maps.ts`：清单查询、Polygon/MultiPolygon 校验、本地加载。
- `src/hooks/use-screen-scale.ts`：16:9 等比缩放；`use-clock.ts`：实时时钟。
- `src/test`：数据层、地图校验、下钻交互、图表生命周期与浏览器回归。

## 地图合规说明

- 地图源为阿里云 DataV.GeoAtlas（areas_v3 2021.5），**仅供学习交流**，未取得商用、修改、公开再分发许可。
- 中国地图完整（含台湾、含南海诸岛九段线 `100000_JD`），要素未裁剪、未修改。
- 行政区码全部来自 GeoJSON `properties`；坐标系未独立核实，禁止叠加外部地理点位。
- 区县为最细下钻层级；台湾省与直筒子市（东莞/中山/嘉峪关等）在 DataV 无下级资产，下钻显示错误或叶级提示并保留原层（属预期）。

## 验证边界

- 全部指标为固定种子演示数据，不代表真实统计。
- 构建含 ECharts 手动分包体积提示（charts ≈ 626KB / gzip 210KB）。
- 大屏按等比缩放，低于约定尺寸的窗口文字同比缩小，不做响应式重排。
