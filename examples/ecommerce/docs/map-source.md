# 地图来源与限制

2026-10-15 已读取 https://datav.aliyun.com/portal/school/atlas/area_selector 正文：

> 本页面数据来源于高德开放平台，该版本数据更新于2021.5，仅供学习交流使用。

数据版本 areas_v3。逐文件来源、下载时间、字节、SHA-256 见 src/data/maps/manifest.json。原始文件在 public/maps，不修改坐标、不简化、不移除岛屿；运行时仅将属性 adcode 转字符串，区县展示从父文件提取完整 Feature。全国附属要素 100000_JD 保留但不作为行政区，不赋业务指标。

实际下载 363 文件，27,128,103 字节；树含 3238 节点（含全国），35 条来源无下级记录，详见 docs/maps-download.log。未逐项对照官方现行行政区名录，不能称为当前全国区县无遗漏。直辖市不人为插入市级。无子级区域显示原因。
