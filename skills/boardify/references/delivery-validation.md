# 交付验证与证据强制门禁

## 判定原则

“代码已写”“页面能打开”“构建成功”“截图好看”分别只证明局部事实，任何一个都不能单独证明交付完成。必须同时满足需求、工程、运行、交互、数据、视觉和适用的地图门禁。

门禁状态只允许：通过、失败、受阻、不适用。证据缺失或未执行一律为受阻；执行后不满足预期为失败。不适用必须有需求范围依据与确认记录，不能用来绕开未实现功能。禁止用加权总分抵消任一强制门禁失败。

## 证据记录格式

每条记录必须含：证据编号、需求编号、门禁编号、检查对象、代码版本或文件哈希、环境与依赖版本、时间与时区、数据样本版本、前置条件、命令或真实操作步骤、预期、实际、退出码或断言结果、日志／截图／录屏位置、结论、执行者及未解决问题。

证据放在用户允许的交付位置；未经授权不扩展写入范围。若不允许保存文件，可在交付记录中保留可复核的命令结果和操作结果，说明图片证据无法持久化的限制；缺少门禁要求的必要证据仍是受阻。

不能把设计稿、静态占位、源站示例、模拟工具输出或程序直接修改状态后的截图当作真实用户操作证据。截图与日志必须来自同一待交付版本；修复后重跑受影响用例，旧版本证据不得冒用。

## 强制门禁矩阵

| 门禁 | 必做检查 | 最低证据 | 阻断条件 |
| --- | --- | --- | --- |
| G-01 范围 | 对照需求编号和文件变更清单 | 需求映射、实际新增修改列表 | 缺失关键需求或越权改动 |
| G-02 可复现 | 按锁文件安装，执行真实存在的类型、静态检查、测试与构建 | 命令、目录、版本、退出码、日志 | 失败、未执行或未说明缺失检查 |
| G-03 运行 | 启动生产产物，打开入口和关键深层路由并刷新 | 实际地址、启动结果、浏览器结果 | 仅开发模式有效、白屏或资源路径错误 |
| G-04 交互 | 筛选、排序、重置、详情、导出及所有可见操作 | 真实操作前后结果与断言 | 按钮无效、虚假成功或状态不一致 |
| G-05 数据 | 手算样本与界面、图表、表格、导出比对 | 输入、计算式、期望值和实际值 | 口径不一、缺失补零、演示冒充真实 |
| G-06 异常 | 空数据、超时、拒绝权限、服务错误与恢复 | 故障注入方法、错误表现、恢复记录 | 永久加载、静默失败或无重试路径 |
| G-07 视觉 | 约定视口、长文本、极值、主题与缩放 | 每个适用视口截图和人工观察结论 | 内容裁切、不可读、意外页面溢出 |
| G-08 可访问 | 键盘操作、焦点、标签、对比度、图表替代数据 | 操作记录、测量值、可访问结构结果 | 关键任务只能鼠标执行或只靠颜色 |
| G-09 图表 | 执行 echarts.md 的 E-01 至 E-06 | resize、更新、卸载、性能记录 | 残留实例、重复事件、错误系列或性能超预算 |
| G-10 运行健康 | 检查控制台与关键网络请求 | 控制台结果、状态码与资源失败清单 | 未解释的应用错误、关键请求失败 |
| G-11 地图合规 | 逐资产核对许可、分发、审图适用性、版本与署名 | 清单、授权依据、责任人确认 | 许可未知、借用审图号、边界合规未确认 |
| G-12 地图空间 | 校验坐标系、转换链、控制点、区域码映射 | 误差表、阈值、哈希和映射检查结果 | 坐标未知、重复转换、错误区域关联 |
| G-13 地图行为 | 实际下钻、返回、竞态、叶子、缺图与离线本地加载 | 分层截图、操作记录、网络证据 | 只换标题、回退失效、迟到响应覆盖或热链依赖 |
| G-14 交付完整 | 核对启动方式、限制、来源、证据索引和版本 | 交付清单与未解决项 | 声称完成但证据不可复核 |

G-09 对 ECharts 实施适用；G-11 至 G-13 对地图功能适用。未承诺地图且应用没有地图时可记录不适用；已承诺地图但缺许可只能受阻，不能降为不适用。

## 执行顺序

1. 固定待测版本、样本数据、浏览器、视口、主题、网络条件与性能预算，记录基线。
2. 完成静态检查与生产构建。没有脚本时明确记录检查缺口，经允许补充或使用等价可复现检查；不能捏造命令成功。
3. 启动生产产物，确认服务实际响应后再提供预览。浏览器打开页面，检查控制台、网络和初始状态。
4. 通过真实点击、输入和键盘执行主路径，用 DOM 断言、数值比对及截图互相补充；Canvas 图表额外检查可见结果和数据表，不能只查 canvas 元素存在。
5. 执行异常、连续切换、重新进入页面、主题与视口变化；地图按 china-maps.md 执行专项用例。
6. 记录失败，完成修复后重跑对应门禁与受影响回归；必要证据采集完成后再判定交付状态。

## 浏览器自动化实测技巧

- **ECharts 地图（roam 开启）上的合成点击可能被判定为微拖拽而不触发 click**。自动化验证下钻时用完整事件序列替代单击 API：依次派发 `mousedown`、`mouseup`、`click`，坐标取同一位置。
- **shadcn/Radix 元素（Select 触发器、部分按钮）自动化点击可能 actionability 超时**，降级用 `evaluate` 找到元素直接 `.click()`，再轮询状态变化。
- **定位 canvas 内的区域别靠经纬度换算**（比例与内边距易错）：先截图看渲染标签，或对候选点循环尝试并轮询面包屑变化。
- **后台标签页 rAF 被节流**：数字滚动等动画会卡在初始值，截图前确认标签页可见；动画实现可带定时器兜底落值。
- 判断“点击落空”还是“功能坏了”：悬停出 tooltip = 事件通、点位对；无 tooltip = 点在空白处。
- 断言图表状态优先读数据替代（表格、结论文字、DOM 属性），不以 canvas 元素存在代替可见性；地图还要断言多个实际填充色，不能只验证 SVG 存在。

## 常见故障速查

| 症状 | 根因 | 修复 |
| --- | --- | --- |
| 整页空白 | 运行时 JS 错误 | 浏览器 console 看第一条错误 |
| 图表空白、无报错 | 容器高度 0 | CardContent 定高；flex 加 `min-h-0` |
| Map xxx not exists | 未注册就渲染 | 先 `await loadGeo(code)` 完成 registerMap 再 setOption |
| geojson 404 | 资源未本地化 | 运行 fetch-maps.mjs 下载对应 adcode 到 public/maps |
| 样式全丢 | Tailwind 未生效 | 检查 index.css 是否引入 tailwind；重启 dev |
| 端口被占 | 默认口冲突 | `--port` 换口，同步改访问地址 |
| tooltip 被裁剪 | 溢出容器 | `tooltip.confine: true` |
| 构建产物子路径部署 404 | base 不对 | vite.config 设 `base: './'` 或实际子路径 |
| 地图填不上色 | 数据名与 GeoJSON 全称不一致 | 数据层产出全称或做简称映射 |

## 地图最小验收场景

必须至少选择一条确有授权资产的多级路径，验证全国 → 省 → 可用子级 → 返回省 → 返回全国；实际只支持两级则按批准范围验证两级，并禁止声称支持三级。其他场景包括快速 A/B 切换、加载中返回、无子级区域、无业务数据区域、损坏文件、缺失文件、离线冷启动和恢复网络。

每个场景核对边界、区域名、面包屑、图例、指标、表格和返回后的缩放状态。不以手动设置内部状态代替下钻。离线验收应保留本地服务可达、阻断外网并使用清空缓存的新会话；如果承诺完全断网运行，还须验证相应离线分发／缓存机制，二者不可混称。

## 交付结论模板

- 状态：已通过全部适用门禁／部分完成且受阻／验证失败。
- 范围：需求编号及本次新增修改文件，明确不包含的能力。
- 运行：实际验证过的安装、构建、启动方法和入口；未运行则直说未运行。
- 证据：门禁编号、结论、对应记录位置与待测版本。
- 限制：问题、影响、责任方、解除条件；未验证项不得包装成已知正常。
- 来源：资料地址、访问日期、核实级别、许可确认范围。

只有所有适用强制门禁通过，才使用“已完成并验证”。没有浏览器能力、没有地图许可或没有运行环境时交付可说明已完成部分，但必须保持受阻状态并指出所缺证据。

## 模板检查与业务验收

按 SKILL.md 执行 scripts/validate.mjs 与 scripts/verify.mjs 检查模板完整性；两者的地图哈希基线仅适用于未经替换的模板及其副本。业务资产替换后必须建立经核对的资产清单与校验器，不得更新哈希掩盖未知修改，也不得将模板检查结果用于业务验收。

starter 的三级合成地图只能验证演示导航，不能证明真实全国、省、市县覆盖、许可或坐标精度。业务验收须另行执行目标工程测试、构建、生产预览及浏览器真实操作；单元测试不能替代真实图表渲染证据。
