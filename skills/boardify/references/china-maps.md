# 中国地图：许可、坐标、本地化与下钻

## 先决门禁

地图能下载、能显示、带有审图号或位于公开仓库，都不等于允许商用、修改、离线分发或公开发布。ECharts 的软件许可不能授权第三方地理数据。未完成许可和适用性核实，不得把地图资产加入发布包；可用行政区表格替代展示，明确地图功能受阻，不得假称地图已交付。

1. 分别核实数据版权许可、供应商服务条款、离线缓存／再分发权及公开地图审核适用性。
2. 对国家版图、行政界线、岛屿、附图、地名及审图号展示进行核查；禁止自行删改边界、缺省岛屿或把附图当作可随意变形的装饰。
3. 修改颜色、边界、标注、裁切或叠加内容后，不能自动沿用原审图结论。将最终表现形式与用途提交有责任的合规人员确认，必要时向有权机关核实。
4. 不伪造审图号，不借用不适用于当前产品或版本的审图号。“仅供参考”不能替代许可和审核义务。
5. 记录适用法规核查日期与确认责任人；历史官方答复是依据线索，不是当前具体产品的法律结论。

## 资产清单

starter 仅包含明确标记的三级合成 Polygon 示例，不含真实中国行政区地图。其清单用于演示父子导航，不能替代下列来源与许可记录。当前类型和运行时校验器仅支持 Polygon；接入含 MultiPolygon 的真实数据前必须扩展类型、校验器与测试，禁止强转 Polygon 或丢弃岛屿。

每份全国、省、市、区县资产必须有独立记录；清单可以沿用项目现有格式，但必须包含下列字段。资源未具备时留在待核实清单，不生成伪造许可。

| 字段组 | 必填内容 |
| --- | --- |
| 身份 | assetId、adcode 字符串、中文名、level、parentAdcode、行政区划版本日期 |
| 来源 | 原始下载地址、提供方、获取时间、原始文件哈希 |
| 授权 | 许可名称／版本、许可原文位置、商用／修改／缓存／分发范围、署名要求 |
| 审核 | 使用场景、审图适用性结论、适用审图号或不适用依据、确认责任人和日期 |
| 空间 | 源坐标系、目标坐标系、轴顺序、单位、投影、空间范围、精度说明 |
| 处理 | 转换工具与版本、转换链、简化参数、输出哈希、复核结果 |
| 分发 | 本地路径、字节大小、版本、children、可下钻状态与限制原因 |

行政区码保持字符串，不按位数推导所有父子关系；直辖市、省直辖县级单元及行政区调整依据清单显式建树。名称别名只负责展示或受控匹配，重复名称必须由区域码消歧。

## DataV GeoAtlas 资源事实（2026-10 实测）

以下事实来自对 DataV.GeoAtlas `areas_v3` 的实际下载检查，用于防乱答。接其他来源时必须重新核实，不得把这些数值直接套用。

- `100000_full.json` 含 35 个要素：34 个省级行政区 + 1 个九段线要素（`adcode: "100000_JD"`、无 `name`）。九段线是合规表达的一部分，不可过滤删除；识别为附属要素后保留几何，不当作行政子级，不赋予业务数据。
- 省级 `properties.name` 是**全称**：`北京市`、`河北省`、`内蒙古自治区`、`台湾省`、`香港特别行政区` 等，不是“北京／内蒙古／台湾”这类简称。数据行里的简称需经映射转全称，或用区域码关联。
- 每个 feature 的 `properties` 含：`name / adcode / level / childrenNum / center / centroid / parent / acroutes`；几何通常为 MultiPolygon。
- `childrenNum` 实测：甘肃=14、台湾=0（该版本无台湾下级）、香港=18、澳门=8。`childrenNum === 0` 即停止下钻。
- 下载 404 = 该区域无下级数据，属预期：台湾 `710000`、东莞 `441900`、中山 `442000` 在 DataV 均无 `_full` 数据（东莞／中山为直筒子市）。不要反复重试，运行时用 `childrenNum === 0` 或清单缺口拦截下钻。
- 直辖市可直达区县；省直辖县级单元需按清单显式建树，不按位数猜测。

## 坐标系强制规则

- 确认文件声明和供应商说明，不因扩展名为 .geojson 就假设 WGS84。RFC 7946 定义的 GeoJSON 使用 WGS84 经度、纬度十进制度；供应商实际文件是否符合必须单独检查。
- 点位默认接口契约写成 [经度, 纬度]，校验经度 −180 至 180、纬度 −90 至 90；范围校验通过不能证明坐标系正确。
- WGS84、GCJ-02、BD-09 不可直接混叠。高德文档说明其坐标为 GCJ-02；其他供应商逐一核实，不推广为所有地图数据的结论。
- ECharts registerMap 负责注册数据，不会自动完成这些坐标系转换。屏幕投影与地理基准转换是两件事，不能用投影参数“修正”偏移。
- 优先使用来源一致的底图与点位；必须转换时，选合法授权且已验证的方法，在数据边界只转换一次，保存源坐标、目标坐标、工具版本和误差记录。
- 不提供未经验证的逆转换承诺，不为“看起来对齐”手工拖移点位。坐标系未知或转换许可不明时阻断地理叠加。
- 选取至少三个分布于不同位置的已知控制点，按业务精度预算比较误差；确认顺序、单位、范围和重复转换问题。容许误差必须事先约定，不能看图凭感觉放行。

## 本地化与资源加载

1. 只有许可允许时才冻结本地资产，保留来源、许可文本与 SHA-256；本地化不消除授权义务。
2. 资源按版本与行政区码组织，使用清单白名单解析路径；禁止把用户输入直接拼为 URL 或磁盘路径。
3. 首次只载入当前层级，子级懒加载；本地缓存键包含资产版本与区域码，升级时避免旧缓存混入。
4. 加载后校验 FeatureCollection、非空 features、Polygon/MultiPolygon、有限坐标、闭合环、唯一标识及预期范围；验证几何有效性不能代替版图合规检查。
5. 不跨域热链公开示例地图。部署在子路径时验证资源请求；离线模式必须禁用外网后冷启动并实际下钻，不能只依靠上次浏览器缓存。
6. 中文化地名、面包屑、错误提示、单位与图例。缺少行政区数据标为“暂无数据”，不要当作该区域不存在。
7. 如需几何简化，只在授权允许且精度、拓扑和边界表达复核通过后实施，记录输入输出哈希；不得擅自删除小岛或改变合法边界表达。

## ECharts 关联

为每个区域与版本使用唯一 mapKey，完成模块注册和资产校验后调用 registerMap(mapKey, geoJSON)，再在 map 系列或 geo 配置中引用同一个键。数据按区域码关联到受控 feature；可按目标版本支持的 nameProperty 绑定区域码，或在适配层完成唯一映射。显示中文名不应牺牲键的唯一性。

禁止仅依赖 params.name 推断区域身份；必须从数据或映射表取 adcode。无指标区域也要能够显示边界，并按清单决定是否可下钻。色阶、无数据样式、汇总与表格保持一致。

## 下钻与地图交互实测坑

- **下钻场景必须用独立 map series**。`geo` 组件 + `series-map(geoIndex: 0)` 组合虽然能同时填色加打点，但区域点击事件可能不触发，`chart.on('click')` 拿不到下钻数据。填色加下钻直接使用 `series: [{ type: 'map', map: adcode }]` 加 `visualMap`。
- **map series 上叠加 `effectScatter` 会拦截所在区域的点击**（打点恰在区域中心）。需要打点加下钻时给打点系列设 `silent: true` 穿透，或直接不在下钻场景打点。
- **map series 与 geo 组件不要各画一份地图**，会叠两层轮廓。只留一个画地图：填色用 map series；只打点／飞线用 `geo` + `coordinateSystem: 'geo'` 系列。
- 注册与渲染顺序：先 `await loadGeo(code)`（含 registerMap）完成，再 setOption，否则报 `Map xxx not exists`。
- 下钻切换 = 换 `series.map` 的注册名（已用 adcode 注册）+ 换该层数据；返回上级 = 出栈后重新加载栈顶层级。用 `visualMap.max` 取当前层最大值，避免跨层汇总混入色阶。
- 数据名与 `properties.name` 全称不一致时永远填不上色：数据层产出全称，或经 `byName` 索引做简称转全称映射。
- 南海诸岛等附属要素 label 在小尺寸下可能挡版面，可关闭 label，但要素必须保留，不得过滤。
- 无下级区域（`childrenNum === 0` 或清单缺口）点击不动、不崩溃，提供面包屑返回与“已到最细层级”提示。

## choropleth 填色模板

```ts
// 区域填色 + 下钻：必须用独立 map series，不用 geo 组件（见上方实测坑）
// theme 为 useChartTheme 的返回值；色阶只用其中已验证的 hex（mapFrom 低端、primary 高端）
export function buildRegionMapOption(code, rows, maxValue, theme) {
  return {
    tooltip: { trigger: 'item', confine: true },
    visualMap: {
      left: 8, bottom: 8, min: 0, max: maxValue,
      text: ['高', '低'], calculable: true,
      inRange: { color: [theme.mapFrom, theme.primary] },
    },
    series: [{
      type: 'map', map: code, roam: true,
      label: { show: true },
      // name 必须与 geojson properties.name 一致（DataV 全称，如“广东省”）
      data: rows.map(r => ({ name: r.region, value: r.value })),
    }],
  }
}
```

starter 的 `RegionMap` 组件即此模板的完整实现（含竞态隔离、面包屑、重试）。只打点／飞线、无填色下钻：用 starter 的 `buildGeoOption` + `buildMapScatterSeries` / `buildMapLinesSeries`（`coordinateSystem: 'geo'`）。
- `visualMap` 与数据关联：series.data 的 `name` 必须等于要素 `properties.name`；行政区码则通过数据适配层映射，不能只用展示名当业务键。
- 色阶插值颜色若用 oklch 无效，改用 hex（见 design-system.md 的 oklch 兼容坑）。

## 下钻状态机

状态至少包含 currentAdcode、level、breadcrumbs、filters、viewState、requestId、loading、error。只对清单中可用且获准的 children 提供下钻。

1. 点击区域或键盘选择列表项，校验目标确属当前节点子级且资产可用；叶子节点说明“已到最细层级”。
2. 保存当前缩放、中心和筛选快照；发起新请求并递增 requestId，取消或忽略旧请求。
3. 加载地图与同口径业务数据，验证后注册；仅最新请求成功时原子更新地图、表格、标题、图例与面包屑。
4. 失败保持原层级与导航栈，不提前入栈；显示错误、重试与继续查看原层入口。
5. 返回一级或点击祖先面包屑时取消未完成请求，恢复对应层级视图与筛选；不能只改标题不换边界。
6. 快速连续点击、省份 A 后切 B、加载中返回、断网与资源缺失均不得让迟到响应覆盖当前层级。
7. 不保证每个区域都有市／县三级结构；无授权子图或无对应层级时明确禁用，不用全国图冒充下级图。

## 必须提供的验收证据

地图启用时，delivery-validation.md 的地图门禁必须全部适用：许可清单与确认记录、坐标控制点误差、真实全国到子级再返回的操作记录、连续切换竞态、叶子节点、无数据、损坏／缺失文件、断网本地加载与恢复证据。截图须能看到层级、数据范围和来源标识；截图本身不能证明许可合法或坐标精确。
