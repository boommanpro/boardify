# 电商示例实践

## 复用边界

`examples` 分支中的 `examples/ecommerce` 是仅首屏经营大盘，不是管理系统。禁止恢复侧栏、专题导航和长明细页。顶部指标、中央本地中国下钻地图、两侧趋势/渠道/漏斗/品类/履约同时可见；时间、返回、主题和全屏采用紧凑操作。不要将其真实地图复制进通用 starter，也不要用该示例的测试结果替代新工程验收。用户批准的方案无需重复审批。

首屏以视口高度网格和可收缩图表容器适配 2560×1440、1920×1080、1366×768，不使用整体缩放或隐藏溢出伪造无滚动。行政区采用紧凑选择器作为键盘替代入口。截图必须为视口截图，并测量页面双轴尺寸、面板边界和图表实际尺寸。目标之外的小屏可重排滚动，不宣称已通过首屏验收。

## 一致模拟数据

- 固定种子、版本、自然日时区、金额整数分；只生成一次事实集合，再按共享筛选聚合。
- 明确访问次数不是跨日去重访客，新老客分组不是去重用户数，模拟订单不是实际交易。
- 每个维度分组加总必须等于卡片汇总；支付、发货、签收须满足包含关系。比例分母为零显示缺失而非假造增长。
- 时间筛选、地图下钻与返回共用同一状态；地图成功后才提交地域，失败保留原图与数据。重置恢复日期，不隐式改变地域；返回全国通过地图路径完成。

## 地图接入陷阱

- DataV 源站标明 2021.5、来源高德、仅供学习交流；可下载不能推出商用、缓存再分发与公开地图审核许可。独立本地学习验证仍不得宣称所有合规门禁通过。
- 源文件原始字节保存并哈希；运行适配层可将 adcode 数字规范为字符串，不更改坐标。`nameProperty: 'adcode'` 对应的数据键也须是字符串，否则边界可见但业务颜色关联可能失效。
- 全国文件存在 `100000_JD` 空名称附属要素。明确识别并保留几何，不视为行政子级，不赋予模拟订单，不为清理空名称删除它。
- Polygon 与 MultiPolygon 均逐环检查。原始哈希、manifest 哈希基线与树关联分别验证；哈希证明完整性，不证明地图准确、许可或审图合规。
- 直辖市可直接到区县，东莞等来源无下级，台湾省在本版来源无子图；实际清单缺口必须可见，不能自动补层级。
- 每资产记录原始 URL、时间、字节、哈希；清单记录版本、来源用途限制、坐标未核实状态、覆盖缺口。

## 必须追加的运行检查

三个约定桌面尺寸的全新浏览器上下文，阻断外网而保留本地生产服务器；实际点击图形、键盘操作、全国省市区返回、直辖市、无子图、空数据、错误重试、明暗主题、全屏进入退出、取消加载与快速切换。检查多个实际填充色，避免仅验证 SVG 存在。SVG 的水平网格 path 高度为零，不能用第一个 path 的可见性来代替图表可见性。当前入口为 `npm run test:browser`，证据保存在 `docs/evidence/single-screen`；旧六专题证据仅为历史记录。

维护实例生命周期与配置更新分离，数据变化用版本支持的替换策略，不每次 dispose。测试包括选项更新不销毁、主题变化清理、事件仅接受目标 seriesType。
