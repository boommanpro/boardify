# 需求与实施契约

## 使用边界

本参考用于 boardify 仪表盘、数据看板与中国地图可视化任务。所有“必须”“禁止”均为项目门禁；建议值不是外部标准。用户明确约束优先于默认建议；涉及许可、安全、数据真实性及交付证据的门禁不得静默省略。

## 开始实施前

1. 读取现有目录、依赖清单、锁文件、脚本、路由、组件和主题；不得假定 React、shadcn、ECharts 已安装。空项目记录“无既有技术栈”，先确定技术方案。
2. 从用户原文提取已确定事项；已经批准的方案不重复征询。只对会改变范围、权限、数据含义或验收结果的缺失信息追问。
3. 用下表形成需求契约。暂缺内容标记“待确认”，写明影响、负责人和解除条件；禁止把猜测写为已确认。
4. 每项需求赋予稳定编号，例如 R-01；关联实现入口、测试编号、证据编号。未完成关键需求不得宣布交付。

| 必填项 | 必须记录的内容 | 阻断条件 |
| --- | --- | --- |
| 用户与决策 | 谁使用、要回答的问题、主要操作 | 无法确定核心任务 |
| 交付形态 | Web 看板（响应式）或数据大屏（16:9 等比缩放）；单屏无滚动目标分辨率 | 无法确定布局验收标准 |
| 页面范围 | 路由、模块、权限、明确不做什么 | 范围存在冲突 |
| 指标字典 | 字段、来源、单位、时间粒度、时区、聚合与分母 | 核心指标口径不明 |
| 数据方式 | 真实接口或演示数据、更新频率、延迟、脱敏方式 | 无权限或真实性不明 |
| 交互 | 筛选、联动、排序、重置、导出、详情与返回 | 只有视觉描述而无行为定义 |
| 地图范围 | 层级、行政区版本、坐标系、覆盖范围、许可 | 地图来源或许可未确认 |
| 运行环境 | 框架版本、浏览器、设备、部署基础路径、联网条件 | 无法复现运行 |
| 验收预算 | 视口、数据量、性能阈值、测试与证据位置 | 核心门禁无判定标准 |

## 默认假设表（不为问而问）

信息足够或需求含糊但默认假设合理时，采用下表并**在回复中声明假设**，不挤牙膏式连环追问。关键维度缺失且两种做法工作量差异大（如大屏 vs 看板、mock vs 接 API）时才用选项询问。

| 维度 | 默认值 |
| --- | --- |
| 交付形态 | Web 看板（响应式、亮色、暗色可切换）；用户说“大屏／指挥中心／投屏／值守”则按 16:9 大屏 |
| 数据 | 结构化模拟数据，集中在数据层管理，字段与真实数据同构 |
| 指标 | 用户提到的全上；未提到的补常用 KPI 并在回复声明 |
| 主题 | 按业务场景从内置品牌色预设选定（green/blue/amber/violet/neutral/teal/rose/midnight，写入 `index.html` 的 `data-palette`）+ 明暗可切换，用户偏好可运行时覆盖（见 scenarios.md 配方总览）；用户有品牌色则问 hex 并定制预设变量块 |
| 地图 | 全国 + 下钻到市级；涉及地图时仍需确认来源与许可 |
| 首屏形态 | 默认单屏看板（目标分辨率无滚动无裁切）；明确的系统需求才做多页管理系统 |

## 数据语义

- 时间明确采用业务时区；默认建议 Asia/Shanghai，但不得据此改写已存在的业务时区。接口时间戳与显示格式分离。
- 金额注明币种与元／万元等缩放；百分比明确比例值或百分点；同比、环比写出比较窗口和分母为零时的展示规则。
- 区分零、缺失、无权限、未加载、请求失败。缺失默认显示“暂无数据”，不得补零伪造趋势。
- 指标、图表、地图和表格必须共享筛选状态与聚合口径；不能为每张卡片生成互不一致的随机数。
- 演示数据必须显著标明“演示数据”，使用固定数据或固定种子，保留边界样本；禁止冒充实时数据。
- 导出与屏幕使用同一过滤条件、单位、时间范围和权限；导出字段及敏感信息处理必须事先明确。

## 行为验收格式

每项交互写成“给定状态 → 用户动作 → 可观察结果 → 异常恢复”。例如：给定全国视图和本月筛选，选择一个有已授权子级资产的省，地图与表格同时进入省级范围、面包屑增加一级；返回后恢复全国筛选与视图；加载失败保留原视图并可重试。

必须覆盖初始、加载、成功、空数据、错误、无权限与过期数据状态；确实不适用的状态记录理由，不得直接删除检查项。按钮必须执行真实动作或明确禁用原因，禁止仅弹出“操作成功”掩盖未实现。

## 实施顺序

先确认数据与交互，再按 engineering.md 建立工程约束，按 design-system.md 固定视觉规则，按 echarts.md 实施图表；涉及地图时先通过 china-maps.md 的许可门禁。最终一律按 delivery-validation.md 判定，不允许用截图替代功能验证。
